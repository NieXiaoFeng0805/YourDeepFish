# 桌宠「小肥鱼」技术方案 v0.1

> 状态：草案，待主人确认宿主形态与动画档位。
> 环境实测：Windows 11 10.0.26200 / Node v24.14.0 / Python 3.12.10 / WebView2 156.0.4314.58 / 未装 Rust、pnpm。

---

## 1. 项目定位

一只常驻 Windows 桌面的 Q 版角色：无边框、透明、置顶、可拖拽、可穿透点击，具备待机/眨眼/被拖抗议/说话等状态，可选接入大模型对话与语音。

一句话目标：**开机自启、不挡事、摸鱼时能陪聊的桌面同事。**

## 2. 宿主形态

| 形态 | 能否覆盖桌面 | 交互范围 | 结论 |
| --- | --- | --- | --- |
| 独立 EXE（真桌宠） | 是 | 全局，可拖到任意窗口上方 | **推荐** |
| VSCode 扩展（WebviewPanel） | 否 | 仅编辑器内一块区域 | 若强调「插件」字面 |
| 浏览器扩展 | 否 | 仅网页内浮层 | 网页陪伴场景 |
| DSH 客户端插件 | 否 | 仅 Web GUI 内 | 与当前 Harness 绑定，做不出桌宠 |

> 「插件」一词需先定宿主，这是唯一影响整体架构的分叉点。

## 3. 技术栈选型

| 维度 | Electron | Tauri 2 | WPF (.NET 8) | PySide6 |
| --- | --- | --- | --- | --- |
| 安装包 | 约 85–105 MB | 约 3–8 MB | 约 60 MB（自包含）/ 2 MB（依赖运行时） | 约 60–90 MB |
| 常驻内存 | 140–240 MB | 40–90 MB | 40–80 MB | 60–120 MB |
| 透明 + 像素级穿透 | 原生 API 支持 | 需自写全局光标轮询 | 最精准 | 支持，较笨重 |
| Live2D | pixi-live2d-display / 官方 Cubism Web SDK | 同（走 WebView2） | 困难 | live2d-py，可用 |
| 上手成本 | 低（Node 已就绪） | 中（需 rustup，约 1.2 GB） | 中 | 低 |
| 打包与更新 | electron-builder，成熟 | 成熟 | 一般 | 一般 |

**结论**：优先 Electron + TypeScript + Vite。若主人对体积有硬指标（< 20 MB），改 Tauri 2。

## 4. 形象与动画路线

| 路线 | 素材成本 | 表现力 | 风险 | 定位 |
| --- | --- | --- | --- | --- |
| A. 伪动画（单图微动） | 低 | 中 | 几乎为零 | **MVP 起步** |
| B. 关键帧序列帧 | 中 | 中高 | AI 生成帧易抖动、难对齐 | 2–3 组动作 |
| C. 拆件 + 骨骼 / Live2D | 高 | 高 | 拆件与绑定工时最大 | 正式版 |
| D. Spine / Rive | 高 | 高 | 工具链与授权 | 备选 |

针对现有两张素材（900² JPG 与 1254² PNG，均为白底、Q 版大头、猫耳 + 鱼尾、含一张「哼！」气泡图）的判断：

- 头身比约 1 : 1.6，头部占比大，非常适合做**微动**：呼吸、眨眼、歪头、发丝与鱼尾摆动。
- 第二张可直接作为 `pout`（生气）状态；「哼！」气泡建议不要烘进图片，改用 HTML 气泡层，便于换成中文文案与后续对话内容。
- 两张图均为白底，必须先抠图；白色围裙与白色背景同色，是抠图最易翻车处，需人工修蒙版。

## 5. 推荐架构

```
桌宠小肥鱼/
├─ electron/              主进程
│  ├─ main.ts             窗口、托盘、单实例、自启
│  ├─ window.ts           透明窗创建、置顶维持、多屏定位
│  ├─ hit-test.ts         像素级穿透调度
│  └─ store.ts            配置与密钥（safeStorage 加密）
├─ src/                   渲染进程
│  ├─ stage.ts            渲染循环、图层
│  ├─ state-machine.ts    状态机与权重
│  ├─ physics.ts          重力、投掷、边缘吸附
│  ├─ bubble.ts           气泡对话
│  └─ llm.ts              对话接口
├─ assets/char/           拆件 PNG（命名见 §9）
└─ docs/
```

数据流：主进程维护窗口位置与层级 → 通过 IPC 下发指针/屏幕边界 → 渲染进程做状态机与物理积分 → 回写窗口坐标（限频 60 Hz）。

## 6. 关键技术点

### 6.1 透明无边框窗口

```ts
const win = new BrowserWindow({
  width: 360, height: 420,
  transparent: true, frame: false, hasShadow: false,
  resizable: false, skipTaskbar: true, alwaysOnTop: true,
  backgroundColor: '#00000000',
  webPreferences: { backgroundThrottling: false },
});
win.setAlwaysOnTop(true, 'screen-saver');
```

注意：`backgroundThrottling: false` 必须开，否则失焦后动画掉帧；透明窗口不要叠加 `vibrancy`/`backgroundMaterial`。

### 6.2 像素级点击穿透

默认 `win.setIgnoreMouseEvents(true, { forward: true })`，鼠标移动事件仍转发到渲染进程；渲染进程对当前帧做 alpha 采样，命中不透明像素时关闭忽略。

```ts
window.addEventListener('mousemove', throttle((e) => {
  const a = sampleAlpha(e.clientX, e.clientY); // 离屏 canvas getImageData
  api.setIgnore(a < 0.05);
}, 33));
```

采样节流 30 Hz，避免频繁切换造成指针闪烁。

### 6.3 拖拽与投掷

不要用 `-webkit-app-region: drag`（会吞掉点击事件）。手动记录指针轨迹求速度，松手后按初速度做抛物线，落地按 restitution 0.35 反弹，最终吸附到最近屏幕边缘。

### 6.4 多屏与 DPI

坐标一律用 DIP；跨屏时以 `screen.getDisplayNearestPoint` 重算边界，避免高 DPI 缩放下角色「瞬移」。

### 6.5 托盘、自启、单实例

```ts
if (!app.requestSingleInstanceLock()) app.quit();
app.setLoginItemSettings({ openAtLogin: true, args: ['--hidden'] });
```

Tray 图标必须保留全局引用，否则会被 GC 掉导致托盘图标消失。

### 6.6 打包

electron-builder 输出 NSIS 安装包 + portable 单文件；ico 需含 16/32/48/256 多尺寸。未签名安装包在 SmartScreen 会弹警告，可后续补签名。

## 7. 行为状态机

```
idle ─┬─ blink（2.4–5.6 s 随机）
      ├─ walk（沿屏幕底边慢走）
      ├─ drag（按住）→ throw → fall → land → idle
      ├─ pout（拖拽超 3 s 或连续点击 5 次）
      ├─ talk（对话中）
      └─ sleep（空闲 45 s）
```

- 拖拽可打断任意状态（高优先级）。
- 每 20 次交互插入一次随机小动作（歪头/摆尾），避免机械感。
- 状态权重与冷却时间写在 JSON 配置里，便于调参。

## 8. 对话与语音（可选）

| 能力 | 方案 | 备注 |
| --- | --- | --- |
| 气泡 | HTML 层，跟随窗口顶部 | 9 s 自动淡出，可点击关闭 |
| 大模型 | OpenAI 兼容接口 | key 用 `safeStorage.encryptString` 存 electron-store |
| TTS | Chromium `speechSynthesis`（调用系统 SAPI，zh-CN） | 离线可用；备选 edge-tts |
| 口型 | 音量驱动 3 帧嘴型 | 不做精确音素对齐 |

## 9. 素材流水线

1. **去白底**：BiRefNet 或 rembg（isnet-anime 模型）→ 1024 PNG，边缘 1–2 px 羽化，围裙处人工补蒙版。
2. **拆件**（PS / Affinity）：`back_hair`、`front_hair`、`ear_L/R`、`face`、`eye_open/eye_closed/eye_star`、`mouth_idle/mouth_open/mouth_pout`、`body`、`arm`、`tail`、`apron`。
3. **微动参数**：呼吸缩放 1.00 → 1.02、位移 1–2 px、周期 3.2 s；眨眼 0.08 s；发丝用网格变形或简易 2D 骨骼。
4. **表情**：用第二张图出 `pout`；其余表情靠眼睛/嘴巴图层叠加实现。
5. **可选 Live2D**：Cubism 5 拆件绑定，Web 端用官方 Cubism Web SDK 或 pixi-live2d-display（2.1/4 运行时）。
